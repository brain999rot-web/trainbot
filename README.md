# Telegram Fitness Bot

Повнофункціональний Telegram-бот персонального тренера для створення тренувальних програм та відстеження прогресу.

## Особливості

- 🏋️ **30+ спеціалізованих цілей** - від великих рук до збалансованого розвитку
- 📊 **Автоматична генерація програм** - бот сам підбирає оптимальний сплит та вправи
- 📈 **Відстеження прогресу** - логування тренувань та аналіз прогресії
- 🎯 **Система прогресії** - автоматичні рекомендації щодо збільшення ваги
- 💪 **Науковий підхід** - використання RIR, ефективних підходів, періодизації
- 🔄 **Делод система** - автоматичні рекомендації відновлення

## Технології

- Python 3.12+
- aiogram 3.x
- SQLAlchemy (async)
- SQLite
- aiosqlite

## Встановлення

1. Клонуй репозиторій:
```bash
git clone <repository_url>
cd bot
```

2. Встанови залежності:
```bash
pip install -r requirements.txt
```

3. Створи `.env` файл на основі `.env.example`:
```bash
cp .env.example .env
```

4. Додай токен бота в `.env`:
```env
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_URL=sqlite+aiosqlite:///training_bot.db
```

5. Запусти бота:
```bash
python bot.py
```

## Використання

### Перший запуск

1. Відправ `/start` боту
2. Заповни анкету (вік, зріст, вага, стать, досвід, кількість тренувань)
3. Створи програму через меню "🏋 Створити програму"

### Основні команди

- **🏋 Створити програму** - Створення нової тренувальної програми
- **📋 Моя програма** - Перегляд поточної програми
- **➕ Записати тренування** - Логування виконаних вправ
- **📈 Мій прогрес** - Статистика та прогрес
- **🔄 Пересчитати програму** - Оновлення програми
- **⚙ Налаштування** - Профіль користувача
- **📚 Довідка** - Інструкція

### Логування тренування

1. Натисни "➕ Записати тренування"
2. Обери тренування зі свого сплиту
3. Обери вправу
4. Введи результат кожного підходу у форматі: `вага повторення`
   - Приклад: `50 10` (50 кг, 10 повторень)
5. Бот автоматично проаналізує твій прогрес та дасть рекомендації

## Методологія

Бот використовує сучасні принципи тренувань:

- **Прогресивне перевантаження** - поступове збільшення навантаження
- **RIR (Reps in Reserve)** - контроль інтенсивності (1-2 RIR)
- **Ефективні підходи** - 12-26 підходів на м'яз на тиждень
- **Оптимальна частота** - 2-3 рази на м'яз на тиждень
- **Періодизація** - делод кожні 6-10 тижнів
- **Автоматична корекція** - рекомендації по збільшенню ваги

## База даних

Структура БД включає:

- **users** - профілі користувачів
- **programs** - тренувальні програми
- **workouts** - записи тренувань
- **exercise_logs** - логи виконання вправ
- **exercises** - база вправ

## Розробка

### Додавання нової мети

1. Відкрий `utils/goals.py`
2. Додай новий `Goal` об'єкт до `TRAINING_GOALS`
3. Вкажи пріоритети м'язів та рекомендований сплит

### Додавання нової вправи

1. Відкрий `utils/exercise_database.py`
2. Додай новий `ExerciseData` об'єкт до `EXERCISE_DATABASE`
3. Вкажи обладнання, м'язи, складність
