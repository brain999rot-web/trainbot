### Корінь проблеми:

**Користувачі не завершили реєстрацію!**

При перевірці бази даних виявлено:
```sql
SELECT telegram_id, username, age, workouts_per_week FROM users;

telegram_id | username | age  | workouts_per_week
828738804   | Diola_15 | NULL | NULL
1239422538  | NULL     | NULL | NULL
```

**Причина:** Коли користувач не завершує реєстрацію (не заповнює age/workouts_per_week), 
бот не показує головну клавіатуру з кнопками. Обробники існують і працюють, але користувач 
фізично не бачить кнопки для натискання.

## ✅ Виправлення

### 1. Додано команду `/menu` для відновлення клавіатури

**Файл:** `handlers/registration.py`

```python
@router.message(Command("menu"))
@safe_handler
async def cmd_menu(message: Message):
    """Показати головне меню"""
    await message.answer(
        "📱 **Головне меню**\n\nОбери дію:",
        reply_markup=get_main_menu_keyboard(),
        parse_mode="Markdown"
    )
```

### 2. Виправлено обробник "Довідка" - тепер показує клавіатуру

**Файл:** `handlers/registration.py`

**Було:**
```python
await message.answer(help_text)
```

**Стало:**
```python
await message.answer(help_text, reply_markup=get_main_menu_keyboard())
```

### 3. Додано parse_mode="Markdown" для обробника "Налаштування"

**Файл:** `handlers/registration.py`

### 4. Створено скрипт відновлення клавіатури

**Файл:** `fix_keyboard.py`

Скрипт для масової розсилки клавіатури всім користувачам:
```bash

```

## 📝 Інструкції для користувача

### Якщо кнопки не працюють:

1. **Спосіб 1:** Введи `/menu` - відновить клавіатуру
2. **Спосіб 2:** Введи `/start` - почне з початку
3. **Спосіб 3:** Натисни "📚 Довідка" (якщо вона видима) - покаже клавіатуру

### Для завершення реєстрації:

Якщо користувач не завершив реєстрацію, при `/start` бот попросить заповнити анкету:
- Вік
- Зріст  
- Вага
- Стать
- Досвід тренувань
- Кількість тренувань на тиждень

Після завершення анкети клавіатура з'явиться автоматично.
